# Screenshots Directory

Save your UI screenshots in this directory with the following filenames:

1. `admin_dashboard.png` — Screenshot of Admin Dashboard (`admin/dashboard.html`)
2. `alerts_log.png` — Screenshot of Hospital Alerts Log (`admin/alerts.html`)
3. `nurse_dashboard.png` — Screenshot of Nurse Dashboard (`nurse/dashboard.html`)
4. `patient_detail.png` — Screenshot of Patient Detail & Live Chart (`nurse/patient.html`)
5. `reports_export.png` — Screenshot of Export Reports page (`admin/reports.html`)

Once you paste your image files here, GitHub will automatically render them inside the main `README.md` file!
